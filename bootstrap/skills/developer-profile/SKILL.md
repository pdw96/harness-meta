## 개발자 프로필

**언어**: 한국어로 소통
**운영 환경**: Windows 11 + WSL2

## 작업 스타일

- 토큰 절약 최우선 — 불필요한 서브에이전트 스폰 지양
- 서브에이전트는 **독립적 병렬 조사** 또는 **메인 컨텍스트 보호**가 필요할 때만
- 단순 작업(파일 수정, 짧은 검색)은 직접 처리

## 선호도

- 응답은 **핵심만 간결하게** — 불필요한 설명 생략
- 코드 참조 시 `파일명:줄번호` 형식
- 커밋·배포 전 확인 요청
